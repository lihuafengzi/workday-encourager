# 上班鼓励器

一个无需联网、无需安装第三方 Python 包的 Windows 桌面小工具。

## 启动

推荐直接双击 `dist\上班鼓励器.exe`，无需单独安装 Python。

也可以双击 `启动上班鼓励器.bat` 从源码运行；这种方式需要安装包含 Tcl/Tk 的 Python 3。

## 从源码打包

安装 PyInstaller 后，在项目目录运行：

```powershell
pyinstaller --noconfirm app.spec
```

生成的独立程序位于 `dist\上班鼓励器.exe`。

## 使用

默认月薪为 10000 元、每天带薪 8 小时、上班时间 09:00。每月工作日按当前月份自动计算，无需手动填写。修改月薪、工时或上班时间后点击“保存设置”；下次启动会自动载入。

应用按月薪除以本月工作日计算日薪，再除以每日带薪工时计算时薪。2026 年依据国务院办公厅[《关于2026年部分节假日安排的通知》](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)（国办发明电〔2025〕7号）计算，包含节假日和调休补班；其他年份暂按周一至周五估算，并在界面提示。休息日不累计收入。工作日从设定的上班时间起，按实际经过的带薪时间持续累加，金额四舍五入到分；开始前显示 0.00 元，达到当日带薪工时后按日薪封顶。设置保存在 `%APPDATA%\上班鼓励器\settings.json`。
